# TestFlight — Quick Start

Publish to TestFlight, shortest safe path. Links back to the [full guide](../README.md) at every
step.

1. Complete Apple App Store prerequisites and signing — same identity, same steps. See
   [§4-§11](../README.md#4-eligibility).
2. Add a beta app description and beta app review information in App Store Connect. See
   [§12](../README.md#12-configure-distribution-platform).
3. Upload the build. Internal testers get it in minutes; external testers need Apple's beta
   review first. See [§13 Deploy](../README.md#13-deploy).
4. Invite testers (internal: App Store Connect team members; external: link or email). See
   [§12](../README.md#12-configure-distribution-platform).

STOP — VERIFY BEFORE CONTINUING: confirm the beta app description is complete before inviting
external testers — an incomplete one blocks beta review from starting.
