# .NET MAUI App Distribution

An authoritative, verified guide to distributing .NET MAUI mobile applications.

This guide covers the two primary mobile distribution channels, in priority order:

1. **Apple App Store** — public release
2. **Google Play** — public release

Every material instruction is grounded in current, first-party Apple, Google and Microsoft
documentation, with a `Last Verified` date recorded against it. Where a command or output is
shown as executed, it was run and its real result quoted — not written as illustrative text.

## Status

This repository is under active development. The channel catalogue below records what is
documented so far.

See [`docs/maui-distribution-channel-catalogue-v1.0.0.md`](docs/maui-distribution-channel-catalogue-v1.0.0.md)
for the current channel catalogue, and
[`start-here/choose-your-distribution-channel.md`](start-here/choose-your-distribution-channel.md)
for where to begin.

## Scope

Microsoft/Windows application distribution is out of scope for this phase. The objective is
mobile application distribution; Windows distribution may be added later if there is a clear need.
